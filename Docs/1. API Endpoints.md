# API Endpoint Reference

---

## 1. Platform / Institution-Level

| Method | Endpoint | Description | Actor |
|---|---|---|---|
| GET | `/api/platform/schools/check-availability?schoolName=...` | Check subdomain availability | Institution Admin |
| POST | `/api/platform/schools` | Register a school, seed initial Administrator + Director | Institution Admin |
| GET | `/api/platform/schools` | List all schools | Institution Admin |
| GET | `/api/platform/schools/{tenantId}` | Get a school's details/status | Institution Admin |
| PATCH | `/api/platform/schools/{tenantId}/status` | Suspend/reactivate a school | Institution Admin |
| POST | `/api/platform/schools/migrate` | Apply latest schema migration to all tenants | Institution Admin |
| GET | `/api/platform/emails` | List sent/failed email logs | Institution Admin |
| POST | `/api/platform/emails/{emailId}/retry` | Retry a failed email | Institution Admin |

## 2. Identity Module

## 3. Academic Module

| Method | Endpoint | Description | Actor |
|---|---|---|---|
| POST | `/api/units` | Create a Unit | Administrator |
| GET | `/api/units` | List Units | All roles |
| GET | `/api/units/{unitId}` | Get a Unit | All roles |
| PATCH | `/api/units/{unitId}` | Update a Unit | Administrator |
| POST | `/api/courses` | Create a Course | Administrator, Coordinator |
| GET | `/api/courses` | List Courses | All roles |
| GET | `/api/courses/{courseId}` | Get a Course | All roles |
| PATCH | `/api/courses/{courseId}` | Update a Course | Administrator, Coordinator |
| POST | `/api/batches` | Create a Batch | Administrator |
| GET | `/api/batches` | List Batches | All roles |
| GET | `/api/batches/{batchId}` | Get a Batch | All roles |
| PATCH | `/api/batches/{batchId}` | Update Batch details | Administrator |
| POST | `/api/batches/{batchId}/instructors` | Assign an instructor (max 2) | Administrator |
| DELETE | `/api/batches/{batchId}/instructors/{userId}` | Remove an instructor | Administrator |
| POST | `/api/enrollments` | Enroll a student | Administrator |
| GET | `/api/enrollments` | List enrollments | Administrator, Director, Coordinator, Instructor |
| GET | `/api/enrollments/{enrollmentId}` | Get an enrollment | Administrator, Director, Coordinator, Instructor, student (self) |
| POST | `/api/enrollments/{enrollmentId}/request-withdrawal` | Active → WithdrawalRequested | Student (self) |
| POST | `/api/enrollments/{enrollmentId}/approve-withdrawal` | WithdrawalRequested → Withdrawn | Administrator, Coordinator |
| POST | `/api/enrollments/{enrollmentId}/drop` | Active → Dropped, reason required | Instructor, Administrator |
| GET | `/api/enrollments/{enrollmentId}/history` | Status transition history | Administrator, Director, Coordinator, student (self) |

*`Active → Completed` fires automatically via OptimaJet timer at `BATCHES.end_date`.*

## 4. Attendance Module

| Method | Endpoint | Description | Actor |
|---|---|---|---|
| POST | `/api/attendance/wifi-whitelist` | Register a whitelisted AP | Administrator |
| GET | `/api/attendance/wifi-whitelist` | List whitelisted APs | Administrator, Instructor |
| DELETE | `/api/attendance/wifi-whitelist/{wifiId}` | Remove an AP | Administrator |
| POST | `/api/batches/{batchId}/attendance-sessions` | Trigger a session (QR, 1-hour window) | Instructor |
| GET | `/api/batches/{batchId}/attendance-sessions` | List sessions | Instructor, Administrator, Coordinator, Director |
| GET | `/api/attendance-sessions/{sessionId}` | Get session details | Instructor (owner), Administrator |
| POST | `/api/attendance-sessions/{sessionId}/close` | Close a session early | Instructor |
| POST | `/api/attendance-sessions/{sessionId}/scan` | Scan QR (geofence + wifi validated) | Student |
| GET | `/api/enrollments/{enrollmentId}/attendance` | Get attendance records | Instructor, Administrator, Director, Coordinator, student (self) |
| POST | `/api/attendance/{attendanceId}/justifications` | Submit justification | Student (self) |
| GET | `/api/attendance/justifications` | List pending justifications | Instructor |
| PATCH | `/api/justifications/{justificationId}` | Approve/reject | Instructor |
| GET | `/api/enrollments/{enrollmentId}/attendance-summary` | Get cumulative summary | Instructor, Administrator, Director, Coordinator, student (self) |
| POST | `/api/batches/{batchId}/attendance-summary-document` | Generate/fetch summary PDF | Instructor |
| GET | `/api/batches/{batchId}/attendance-summary-document` | Retrieve document | Instructor, Administrator, Coordinator, Director |
| POST | `/api/attendance-summary-documents/{documentId}/request-changes` | Reject before signing | Director |

## 9. Content Module (NeSignalR, Blog, Search)

| Method | Endpoint | Description | Actor |
|---|---|---|---|
| POST | `/api/content` | Create a draft (neSignalR or blog) | Administrator (neSignalR), Instructor (blog) |
| GET | `/api/content` | List content (filter by type/status) | All roles (published only for Student unless own draft) |
| GET | `/api/content/{contentId}` | Get a content item | All roles (published); author/approver (any status) |
| PATCH | `/api/content/{contentId}` | Edit a draft (creates a new version) | Author |
| GET | `/api/content/{contentId}/versions` | View version history | Author, approver role for that type |
| POST | `/api/content/{contentId}/attachments` | Upload an attachment | Author |
| POST | `/api/content/{contentId}/submit-for-approval` | Draft → PendingApproval | Author |
| POST | `/api/content/{contentId}/approve` | PendingApproval → Published (neSignalR: Director; blog: Coordinator) | Director (neSignalR), Coordinator (blog) |
| POST | `/api/content/{contentId}/reject` | PendingApproval → Draft | Director (neSignalR), Coordinator (blog) |
| PATCH | `/api/content/{contentId}/archive` | Published → Archived | Author, approver role for that type |
| GET | `/api/search?q=...&type=neSignalR,blog` | Full-text search across published content (Elasticsearch) | All roles |
